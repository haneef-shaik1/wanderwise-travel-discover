    About WanderWise

    A portfolio-grade, framework-free travel product.

    WanderWise is a front-end project built with only HTML, CSS and vanilla JavaScript. Destination data lives in one JSON file, favourites and itineraries live in your browser, and nothing is sent anywhere.
